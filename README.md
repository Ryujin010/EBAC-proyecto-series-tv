## 📖 Descripción

Sitio sobre series de televisión con estilos organizados y reutilizables gracias a Sass (SCSS) y el uso de la API https://api.tvmaze.com, para la obtención de la información de las series a nivel mundial.

## 🚀 Instalación y uso

Clona el repositorio:

```bash
git clone https://github.com/Ryujin010/EBAC-proyecto-series-tv.git
cd EBAC-proyecto-series-tv
```

Luego:

1. Instala Sass:
   ```bash
   npm install -g sass
   ```
2. Compila los estilos (ajusta las rutas a las de tu proyecto):
   ```bash
   sass --watch scss:css
   ```
3. Abre `index.html` en tu navegador.
